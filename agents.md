# Sitio Web de un centro de FP
---
Este sitio web es de prueba y se usará en clase de Desarrollo de Interfaces Web.
Consiste en un sitio web para un centro formativo de FP.

## Tecnologías
- Frontend: html5, css3, javascript vanilla
- Backend: Node.js, Express 4.22.3, plantillas EJS

## Arquitectura
- Todo en una única página index, dividido por index.

## Contenido de la web
- Debe ser realista
- Debe estar en inglés
- Debe usar imágenes de picsum

## Convenciones del lenguaje
- Usa inglñes para las variables y funciones

## Limitaciones
- No usar grid
